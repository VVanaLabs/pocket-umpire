How it works

1 · SAM watches
Tracks the stumps every frame. Undisturbed for 105 frames = not bowled, geometrically.wicket → 105/105 · id 0
2 · Motion finds the ball
Concepts score zero on a 3px smear, so frame-differencing tracks the delivery line instead — at $0.delivery f76–98 → bat
3 · Spark judges
Contact + end stills, stump state, crowd audio → one JSON verdict in ~3s.{"decision":"legal","runs":6}
4 · Geometry decides
MCC laws in code: crease projection, wide lines, no-ball margins. Models perceive, law arbitrates.LAW margins · 0.03m
